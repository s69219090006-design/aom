บทที่ 8

แท็กฟอร์มและองค์ประกอบรับข้อมูลด้วย HTML

🔗 1. แท็กฟอร์มและแอตทริบิวต์หลัก

  • ใช้แท็ก <form> ในการครอบส่วนประกอบทั้งหมดของแบบฟอร์ม เพื่อรวบรวมและส่งข้อมูล
  • action: กำหนดไฟล์หรือ URL ปลายทางที่เซิร์ฟเวอร์สำหรับรับและประมวลผลข้อมูล
  • method (GET): ส่งข้อมูลผ่าน URL เหมาะกับข้อมูลทั่วไป เช่น การค้นหา
  • method (POST): ส่งข้อมูลแบบซ่อนไปกับ Header เหมาะกับข้อมูลสำคัญหรือความลับ
<!-- ตัวอย่างการสร้างฟอร์มรับข้อมูล -->
<form action="process.php" method="POST">
  <input type="text" name="username">
</form>

🔗 2. ชนิดขององค์ประกอบรับข้อมูล (Input Controls)

  • ข้อความ: <input type="text"> รับข้อความทั่วไป, <input type="password"> รับรหัสผ่าน, และ <textarea> รับข้อความยาว
  • ตัวเลือก: <input type="radio"> เลือกได้ 1 ข้อ, <input type="checkbox"> เลือกได้หลายข้อ, และ <select> รายการดรอปดาวน์
  • ปุ่มดำเนินการ: <input type="submit"> ปุ่มส่งข้อมูล และ <input type="reset"> ปุ่มล้างข้อมูล
<!-- ตัวอย่างการใช้งาน Input แบบต่างๆ -->
<input type="text" placeholder="กรอกชื่อ">
<input type="password" placeholder="กรอกรหัสผ่าน">

<!-- ตัวอย่างปุ่มดำเนินการ -->
<input type="submit" value="ส่งข้อมูล">
<input type="reset" value="ล้างข้อมูล">

🛠️ 3. การตรวจสอบความถูกต้องของข้อมูล (HTML5 Validation)

  • required: บังคับให้ผู้ใช้ต้องกรอกข้อมูล ห้ามเว้นว่าง
  • type="email" / type="url": ตรวจสอบรูปแบบอีเมลหรือ URL ให้ถูกต้องตามโครงสร้าง
  • min / max / maxlength: กำหนดช่วงตัวเลขต่ำสุด-สูงสุด หรือจำนวนตัวอักษรสูงสุดที่อนุญาตให้กรอก
