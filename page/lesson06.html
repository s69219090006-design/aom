บทที่ 6

การสร้างตารางข้อมูล

1. โครงสร้างตาราง HTML พื้นฐาน (HTML Table Blueprint)

  • สร้างตารางด้วยแท็ก <table> โดยกำหนดแถวด้วย <tr> (Table Row)
  • สร้างส่วนหัวตารางด้วย <th> (Table Header) ซึ่งข้อความจะกึ่งกลางและเป็นตัวหนาโดยอัตโนมัติ
  • ใส่ข้อมูลทั่วไปในตารางด้วยแท็ก <td> (Table Data)
<!-- ตัวอย่างโครงสร้างตาราง HTML พื้นฐาน --> <table> <tr> <th>หัวข้อ</th> </tr> <tr> <td>ข้อมูล</td> </tr> </table>

2. การรวมเซลล์ขั้นสูง (Advanced HTML Cell Spanning)

  • colspan: ใช้ขยายหรือผสานเซลล์ข้ามแนวนอน (ผสานคอลัมน์)
  • rowspan: ใช้ขยายหรือผสานเซลล์ข้ามแนวตั้ง (ผสานแถว)
  • ช่วยจัดกลุ่มข้อมูลและสร้างรูปแบบตารางที่ซับซ้อนให้ดูเป็นระเบียบ
<!-- ตัวอย่างการผสานเซลล์ --> <td colspan="2">ผสานคอลัมน์</td> <td rowspan="2">ผสานแถว</td>

3. การตกแต่งตารางด้วย CSS (Modern CSS Table Design)

  • ใช้ border-collapse: collapse; เพื่อรวมเส้นขอบตารางไม่ให้เกิดช่องว่างซ้ำซ้อน
  • กำหนดระยะห่างภายในเซลล์ด้วย padding เพื่อเพิ่มความสบายตาในการอ่านข้อมูล
  • ใช้ Pseudo-class เช่น :nth-child(even) ในการสลับสีแถว (Zebra Striping) เพื่อช่วยให้ดูและแยกแยะแถวได้ง่ายขึ้น
/* ตัวอย่างการตกแต่งตารางด้วย CSS */ table { border-collapse: collapse; } th, td { padding: 10px; } tr:nth-child(even) { background-color: #f2f2f2; }
