การจัดรูปแบบเว็บไซต์ด้วย CSS

1. พื้นฐาน CSS (Cascading Style Sheets)

แนวคิด: ถ้า HTML คือ "การก่ออิฐเทปูน" สร้างโครงสร้างบ้าน CSS ก็คือ "การตกแต่งภายในและภายนอก" (ทาสี เลือกกระเบื้อง จัดวางเฟอร์นิเจอร์) เพื่อความสวยงามและระเบียบในการแสดงผล

ข้อดีของการใช้ CSS
แยกส่วนการทำงานออกจาก HTML ชัดเจน ทำให้ดูแลรักษาง่าย เช่น หากต้องการเปลี่ยนสีองค์ประกอบเดียวกันในเว็บที่มี 100 หน้า การใช้ CSS จะช่วยให้แก้ไขโค้ดเพียงบรรทัดเดียวในไฟล์ส่วนกลาง แทนที่จะต้องตามแก้ใน HTML ทีละหน้า

2. วิธีการเชื่อมต่อ CSS (2 รูปแบบหลัก)

1. การเขียนแบบ Internal (สไตล์ชีตภายใน)

วิธีใช้: เขียนโค้ด CSS แทรกไว้ในไฟล์ HTML โดยตรง ภายใต้แท็ก <style> (มักใส่ไว้ในแท็ก <head>)

ข้อดี: สะดวก รวดเร็ว เหมาะกับเว็บไซต์ขนาดเล็กหรือหน้าเดียว (Single Page)

ข้อเสีย: ไม่สามารถนำสไตล์ไปใช้ร่วมกับหน้าอื่นได้ หากเว็บมีหลายหน้าจะทำให้เกิดโค้ดที่ซ้ำซ้อน

2. การเขียนแบบ External (สไตล์ชีตภายนอก)

วิธีใช้: แยกโค้ด CSS ทั้งหมดไปไว้ในไฟล์ใหม่ (นามสกุล .css) แล้วใช้แท็ก <link> ในไฟล์ HTML เพื่อดึงข้อมูลมาใช้งาน

ข้อดี: เป็น "มาตรฐานระดับมืออาชีพ" ช่วยให้ไฟล์ HTML สะอาดตา และเมื่อต้องการแก้ไขดีไซน์ ก็แก้ที่ไฟล์ CSS เพียงไฟล์เดียว ทุกหน้าในเว็บไซต์จะอัปเดตพร้อมกันทันที
