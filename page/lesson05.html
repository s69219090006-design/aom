บทที่ 5

การจัดการข้อความระดับสูงและสื่อมัลติมีเดีย

1. การจัดการข้อความระดับสูง (Advanced Text Management)

  • การกำหนดสีและขนาด: ใช้ CSS กำหนดสีด้วย color (รองรับชื่อสี, Hex Code เช่น #FF5733, RGB) และขนาดตัวอักษรด้วย font-size (นิยมใช้หน่วย px) โดยคำนึงถึงลำดับความสำคัญทางสายตา (Visual Hierarchy)
  • การใช้งาน Google Fonts: เชื่อมต่อ Google Fonts ผ่านแท็ก <link> ในส่วน <head> ของ HTML และเรียกใช้ผ่าน font-family ช่วยแก้ปัญหาเครื่องผู้ใช้ไม่มีฟอนต์ดั้งเดิม
/* ตัวอย่างการใช้งาน CSS Text & Google Fonts */ body { font-family: 'Sarabun', sans-serif; color: #FF5733; font-size: 16px; }

2. การแทรกรูปภาพและสื่อ (Images & Media)

  • การแสดงผลรูปภาพ: แสดงผลภาพด้วยแท็ก <img> ผ่านการระบุเส้นทางไฟล์ (Source) พร้อมจัดการขนาดไฟล์ภาพให้เหมาะสมเพื่อความรวดเร็วในการโหลดหน้าเว็บ
<!-- ตัวอย่างการแทรกรูปภาพ --> <img src="images/photo.jpg" alt="คำอธิบายภาพ" width="600">

3. การจัดการวิดีโอและเสียง (Video & Audio)

  • มัลติมีเดีย HTML5: ใช้แท็กสื่อมัลติมีเดียของ HTML5 (<video> และ <audio>) แทรกไฟล์ลงหน้าเว็บ พร้อมเปิดใช้แอตทริบิวต์ controls เพื่อแสดงแผงควบคุมการเล่น
<!-- ตัวอย่างการแทรกวิดีโอและเสียง --> <video src="video.mp4" controls></video> <audio src="audio.mp3" controls></audio>

4. การสร้างเฟรมด้วย Inline Frame (<iframe>)

  • การดึงเนื้อหาภายนอก: ใช้ดึงเนื้อหาจากภายนอกมาแสดงบนหน้าเว็บ นิยมนำมาประยุกต์ใช้กับ Google Maps เพื่อแสดงแผนที่ หรือฝังวิดีโอเล่นผ่าน YouTube
<!-- ตัวอย่างการฝัง YouTube ด้วย iframe --> <iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID"></iframe>
