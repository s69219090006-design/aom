บทที่ 1

พื้นฐานและกระบวนการทํางานของเว็บไซต์

1. ความหมายและองค์ประกอบของเว็บ

  • Web Page: หน้ากระดาษแต่ละหน้าที่มีเนื้อหาเฉพาะเรื่อง เช่น หน้าบทความ หรือแกลเลอรี
  • Website: หนังสือทั้งเล่มที่รวม Web Page หลาย ๆ หน้าเข้าด้วยกัน
  • Home Page: หน้าปกหนังสือ หรือหน้าแรกสุดที่ผู้ใช้จะพบเมื่อเข้าเว็บ
  • Web Browser: ทำหน้าที่เป็น "ผู้แปลภาษา" อ่านโค้ด HTML, CSS และ JavaScript แล้วประมวลผลออกมาเป็นหน้าเว็บที่สวยงาม

2. ประเภทเทคโนโลยีเว็บไซต์

  • Static Website (เว็บนิ่ง): โครงสร้างพื้นฐานใช้ HTML/CSS ข้อมูลตายตัว ทุกคนเห็นเหมือนกัน โหลดเร็วและปลอดภัยสูง แต่แก้ไขยากเพราะต้องแก้ที่โค้ดทีละหน้า เหมาะกับเว็บไซต์ประเภท Portfolio
  • Dynamic Website (เว็บเคลื่อนไหว): ทำงานร่วมกับระบบหลังบ้าน (Backend) และฐานข้อมูล (Database) เนื้อหาเปลี่ยนตามการโต้ตอบ เวลา หรือข้อมูลผู้ใช้ เหมาะกับร้านค้าออนไลน์หรือโซเชียลมีเดีย

3. กระบวนการทำงานแบบ Client-Server Model

เปรียบเสมือน "การสั่งอาหารในร้าน" มีขั้นตอนดังนี้

  1. Request (สั่งอาหาร): ผู้ใช้พิมพ์ URL หรือกดลิงก์ผ่าน Web Browser (Client) เพื่อส่งคำขอข้อมูล
  2. Processing (ปรุงอาหาร): เครื่องคอมพิวเตอร์ที่เก็บไฟล์เว็บ (Server) รับคำขอ แล้วจัดเตรียมข้อมูล หรือดึงข้อมูลจาก Database
  3. Response (เสิร์ฟอาหาร): Server ส่งข้อมูลกลับมา ในรูปแบบไฟล์โค้ด HTML, CSS และ JS ผ่านอินเทอร์เน็ต
  4. Rendering (กินอาหาร): Web Browser แปลงโค้ดเหล่านั้น ออกมาเป็นหน้าตาเว็บไซต์ ให้เราใช้งาน
// ตัวอย่างการทำงานของ Client-Server Client → Request → Server Server → Response → Client Browser → Rendering → Web Page
ข้อควรจำ
Client คือผู้ขอข้อมูล ส่วน Server คือผู้ให้บริการข้อมูล และ Web Browser ทำหน้าที่แสดงผลข้อมูล ให้ผู้ใช้สามารถมองเห็นและใช้งานเว็บไซต์ได้

4. มาตรฐานการสื่อสาร (Protocols)

  • URL (Uniform Resource Locator): ที่อยู่หรือลิงก์ที่ระบุตำแหน่งของหน้าเว็บอย่างแม่นยำบนอินเทอร์เน็ต
  • HTTP (Hypertext Transfer Protocol): มาตรฐานหรือภาษากลางที่ใช้ในการรับ-ส่งข้อมูลระหว่าง Client และ Server
