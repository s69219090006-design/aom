บทที่ 7

การทำลิงก์และการเชื่อมโยงด้วย HTML & CSS

1. พื้นฐานการทำลิงก์ (HTML Anchor Tag)

  • ใช้แท็ก <a> (Anchor) ร่วมกับแอตทริบิวต์ href เพื่อระบุตำแหน่งปลายทาง
  • Internal Link: การเชื่อมโยงภายในเว็บไซต์เดียวกัน ใช้โครงสร้าง Relative Path โดยระบุชื่อไฟล์ได้โดยตรง เช่น <a href="about.html"> นิยมใช้ทำแถบเมนูนำทาง (Navigation Bar)
  • External Link: การเชื่อมโยงไปยังเว็บไซต์ภายนอก ใช้ Absolute Path โดยต้องระบุ URL แบบเต็มที่ขึ้นต้นด้วย http:// หรือ https:// เสมอ เช่น <a href="https://www.facebook.com">
<!-- ตัวอย่าง Internal & External Link --> <a href="about.html">เกี่ยวกับเรา</a> <a href="https://www.facebook.com">Facebook</a>

2. เทคนิคการเชื่อมโยง (Link Techniques)

  • target="_blank": ใช้บังคับให้เปิดลิงก์ปลายทางในแท็บหรือหน้าต่างใหม่
  • Anchor Link: การสร้างจุดเชื่อมโยงเพื่อกระโดดข้ามไปยังตำแหน่งต่างๆ ภายในหน้าเพจเดียวกัน
<!-- ตัวอย่างการเปิดแท็บใหม่ และ Anchor Link --> <a href="https://google.com" target="_blank">เปิด Google แท็บใหม่</a> <!-- เชื่อมโยงไปยัง element ที่มี id="section1" --> <a href="#section1">ไปยังหัวข้อ 1</a>

3. การปรับแต่งลิงก์ด้วย CSS (Link States & Styling)

  • กำหนดสไตล์และสีสันของลิงก์ตามสถานะการโต้ตอบของผู้ใช้ (Link States ทั้ง 4 รูปแบบ: :link, :visited, :hover, :active)
  • ตกแต่งลิงก์ด้วย CSS เช่น การลบเส้นใต้ข้อความ (text-decoration: none;) และปรับแต่งส่วนประกอบจนมีลักษณะเป็นปุ่มกดที่สวยงาม
/* ตัวอย่างการตกแต่งลิงก์ด้วย CSS */ a { color: #087ff5; text-decoration: none; } a:hover { color: #006bd6; text-decoration: underline; }
